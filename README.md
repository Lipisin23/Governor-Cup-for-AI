# Кубок Губернатора по искусственному интеллекту | Диспетчер смены

Комплексная система голосового и текстового управления группировкой разнородных роботов в реальном времени.

Проект разработан для полигона соревнований: диспетчер принимает распоряжения оператора (голосом через микрофон или текстом из консоли), формирует упорядоченный план действий с проверкой ограничений безопасности и по TCP-сети раздает команды роботам-исполнителям.

---

## Поддерживаемые роботы

Система координирует работу трех принципиально разных платформ:

1. **EyeCar (Икар / Машинка)**
   - Колёсный робот-автомобиль на базе Raspberry Pi.
   - Низкоуровневое управление сервоприводом руля (GPIO 18) и регулятором хода ESC (GPIO 17) через библиотеку `pigpio`.
   - Поддерживает маневры: движение вперёд/назад, повороты колес, разворот по кругу, экстренную остановку.

2. **PuppyPi (Собака / Пёс)**
   - Четвероногий шагающий робот на базе ROS 1 (Noetic / Melodic).
   - Управление походкой (`trot` / `walk`) через топик `/puppy_control/gait` и скоростью через `/puppy_control/velocity`.
   - Кинематические позы (клиренс, наклон корпуса) через топик `/puppy_control/pose`.
   - Навыки и трюки: «сесть», «лечь», «встать», «дать лапу» (shake hands), «поклониться», «потянуться».
   - Встроенный белый список безопасных действий (`SAFE_TRICKS`), исключающий опрокидывание.

3. **Rover (Ровер / Манул)**
   - Шестиколёсный вездеход на базе ROS 2.
   - Автоматически считывает `ROS_DOMAIN_ID` из конфигурации `~/start_manul_services.sh`.
   - Управление раздельной тягой левого и правого борта (skid-steering) через топик `/speed` (`Int16MultiArray`).
   - Поддерживает движение по прямой, криволинейные дуги и вращение на месте.

## Архитектура и ключевые особенности

- **Полный офлайн для соревнований (Vosk STT)**:
  Распознавание речи работает прямо на ноутбуке оператора без необходимости выхода в интернет (модель `model/` уже входит в комплект). На полигоне с нестабильным Wi-Fi это критично.
- **Голосовая обратная связь (TTS)**:
  Диспетчер подтверждает действия голосом («Готов», «Выполнено», «Стоп», «Икар отключился»). Используется быстрый Windows SAPI либо встроенный синтезатор PowerShell.
- **Лингвистический парсер русского языка**:
  - Понимает живые формулировки и синонимы («пёс», «щенок», «машинка», «курьер», «марсоход»).
  - Умеет автоматически определять контекст: фраза *«дай лапу»* без упоминания имени сразу адресуется собаке.
  - Понимает сложные составные цепочки действий: *«Икар вперёд 3 секунды, затем собака сесть и ровер круг»*.
- **Безопасность и аварийный тормоз (Safety First)**:
  - Любая стоп-команда («стоп», «стой», «тормози», «замри», «всем стоп») прерывает текущий план мгновенно, не дожидаясь окончания таймеров.
  - Фильтрация опасных и физически невозможных команд («сальто», «прыжок», «ныряй»).
  - Защита от неопределенности: если направление или робот не ясны («кто-нибудь вперёд», «поезжай туда»), диспетчер вежливо просит уточнить команду.
- **Мониторинг соединений (Watchdog)**:
  Диспетчер постоянно отслеживает статус сокетов роботов. Если робот внезапно обесточился или потерял Wi-Fi, система сразу фиксирует сбой в логе и предупреждает оператора голосом.
- **Журнал смены (`shift_log.txt`)**:
  Каждое событие (подключение, входящая реплика, сформированный план, статус шагов, экстренные стопы и сбои) протоколируется с точностью до секунды.
- **Режим симуляции (Dry-Run)**:
  Любого клиента (`client_eyecar.py`, `client_puppy.py`, `client_rover.py`) можно запустить на обычном ноутбуке без реального железа и ROS. Скрипты автоматически переходят в режим эмуляции и печатают выполняемые команды в терминале.

## Структура репозитория

```text
├── main.py              # Главная точка входа для запуска диспетчера
├── agent_system.py      # Ядро диспетчера (STT, парсер, TCP-сервер, планировщик, TTS)
├── client_eyecar.py     # Бортовой клиент для машинки EyeCar (pigpio / ШИМ)
├── client_puppy.py      # Бортовой клиент для робособаки PuppyPi (ROS 1)
├── client_rover.py      # Бортовой клиент для вездехода Rover (ROS 2)
│
├── server.py            # Альтернативный сервер с потоковой телеметрией (heartbeat 150 мс)
├── client.py            # Бортовой клиент EyeCar с аппаратным таймером watchdog
│
├── model/               # Локальная модель распознавания русской речи Vosk
├── shift_log.txt        # Файл протокола и журнала смены
├── requirements.txt     # Зависимости Python
└── README.md            # Документация проекта
```

## Быстрый старт

### 1. Подготовка окружения на компьютере диспетчера

Требуется Python 3.8+:

```bash
pip install -r requirements.txt
```

### 2. Запуск диспетчера

Запустите главный скрипт:

```bash
python main.py
```

При старте в консоли отобразится ваш локальный IP-адрес и порт:
```text
=======================================================
  IP диспетчера: 192.168.1.105
  Порт:          9090
=======================================================
Ожидаю подключения роботов (Икар, Собака, Ровер)...
```

Диспетчер параллельно слушает микрофон и ждет ввода команд с клавиатуры.

### 3. Подключение роботов

Перенесите соответствующие файлы клиентов на бортовые компьютеры роботов и запустите их, указав IP диспетчера (например, `192.168.1.105`):

- **На машинке EyeCar:**
  ```bash
  python3 client_eyecar.py 192.168.1.105 9090
  ```

- **На собаке PuppyPi:**
  ```bash
  python3 client_puppy.py 192.168.1.105 9090
  ```

- **На ровере:**
  ```bash
  python3 client_rover.py 192.168.1.105 9090
  ```

После подключения каждого робота диспетчер поприветствует его в консоли и сообщит о готовности к работе.

## Примеры команд

Команды можно произносить в микрофон или вводить текстом в строку `> `:

### Одиночные команды
- `икар вперед 4` — машина едет вперёд 4 секунды.
- `икар круг` — выполнение кругового разворота.
- `собака сидеть` / `сядь` — робопёс садится.
- `собака дай лапу` / `лапу` — робопёс подает лапу.
- `собака потянись` / `поклон` — робопёс выполняет растяжку корпуса.
- `ровер назад 3` — вездеход сдает назад 3 секунды.
- `ровер направо 2` — поворот ровера направо.

### Составные маршруты
- `икар вперед 3 секунды затем собака сесть`
- `ровер вперед 2 секунды, потом икар круг, затем собака лапу`

### Экстренные команды
- `стоп` / `всем стоп` / `замри` — моментальная остановка всех подключенных роботов и прерывание текущего сценария.
- `икар стоп` — остановка только машинки.
- `собака стой` — остановка только собаки.

## Сетевой протокол обмена

Взаимодействие построено на простом и надёжном текстовом TCP-протоколе:

1. **Рукопожатие при подключении:**
   Клиент отправляет строку: `HELLO <eyecar|puppypi|rover>\n`
2. **Команды от диспетчера:**
   Формат пакета: `<КОМАНДА> <ДЛИТЕЛЬНОСТЬ_СЕК>\n`
   Примеры: `FORWARD 3.0\n`, `SIT 2.0\n`, `CIRCLE 6.0\n`, `STOP 0\n`
